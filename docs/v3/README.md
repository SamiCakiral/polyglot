## Principe central

Le graphe partagé décrit la langue. Le modèle personnel décrit les preuves et incertitudes
de l'apprenant. Les vues en arbre ne sont que des projections navigables de ces deux
couches. Le professeur consulte et agit au travers d'outils contrôlés ; il ne devient jamais
la source de vérité pédagogique.
