Importez des cartes et catégories depuis un fichier JSON.

Annuler

📋 Format JSON

Format simple (liste de cartes)

[ {"front": "あ", "back": "a"}, {"front": "い", "back": "i"}, {"front": "う", "back": "u"} ]

Format avec catégories

{ "categories": [ {"name": "Sons A", "color": "#3498db"}, {"name": "Sons K", "color": "#2ecc71"} ], "cards": [ {"front": "あ", "back": "a", "categories": ["Sons A"]}, {"front": "か", "back": "ka", "categories": ["Sons K"]}, {"front": "き", "back": "ki", "categories": ["Sons K"]} ] }

Format vocabulaire

{ "cards": [ { "front": "猫", "back": "chat (neko)", "categories": ["Animaux", "N5"] }, { "front": "犬", "back": "chien (inu)", "categories": ["Animaux", "N5"] } ] }

💡 Les alias question/answer sont aussi acceptés au lieu de front/back.
